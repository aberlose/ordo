# Ordo — functional specification

Source of truth for behaviour. Translated from the French design document validated on 2026-10-09.
If something you need is not here, ask — do not invent behaviour.

## Product

- Desktop app for macOS and Windows, installed locally, one user per machine.
- Purpose: organise, prioritise and visualise a backlog of tasks.
- Works fully offline. No account, no server.
- UI languages: French (default) and English, switchable in settings.
- Appearance: light, dark, or follow the system; colour theme **Ciel** by default, with Aurore, Lavande, Indigo and Corail selectable in settings.
- Name: **Ordo** (Latin "order, rank").

## Core features (from the pitch) — all in MVP

| Feature                        | Behaviour                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Several boards                 | Listed in the sidebar. Create, rename, duplicate, archive, reorder. Each board has an icon and a colour. A new board starts with the three default columns, the board icon and the first colour no board uses yet (blue first, grey last). The ⋯ menu of a sidebar row (or a right click) offers Rename (F2), Icon and colour, Duplicate and Archive. Duplicating asks each time for the copy's name and whether to include the tasks; columns and their settings are always copied, and the copy goes right after the original. Archiving needs no confirmation (it is reversible) and opens the next board; with no board left, the first-launch screen shows. Archived boards leave the sidebar and search and are listed in Archives, where "Restore" puts them back at the end of the sidebar. Boards are reordered by drag and drop (sidebar and collapsed rail) or with ⌥/Alt + ↑↓ on a focused board. Deleting a board comes with the trash. |
| Kanban view                    | Columns side by side, horizontal scroll. A card shows title, priority, tags, due date, attachment count and sub-task progress. The task key (ORDO-42) is **hidden by default**; a board setting to show it comes later.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Search and filters             | Full-text search on title, description and tags. Combinable filters: priority, tag, due date (overdue, this week, no date). Two entry points producing the same active filters: filter buttons with checkbox menus above the board, and typed filters in the command palette (`#tag`, `haute`, `retard`…). Results update live; clear all in one click. Filters are kept per board until the app quits and apply to cards only. Overdue = due before today and not done; this week = due Monday to Sunday of the current week; options of one kind combine with OR. Typed words in French or English; words in double quotes are searched as text. The palette also lists matching tasks of the other non-archived boards (free text only) and sub-tasks, and its empty query shows the 5 recently opened tasks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Columns on the fly             | Added from the board. Settings: name, icon, main colour, number of tasks shown by default (beyond it, a "Show more" button; "no limit" is allowed). This is a **display limit only** — there is no WIP limit; an expanded column folds back with "Collapse" in its header, and the expansion is not remembered across restarts. A new column goes to the right end, "In progress", no limit. Changing the category completes or reopens the column's tasks. Deleting a column (after confirmation) sends it to the trash with its tasks; the last column of a board cannot be deleted. Columns can be reordered by drag and drop.                                                                                                                                                                                                                                                                                                                    |
| Status                         | A task's status **is** its column. Each column has a category (To do, In progress, Done), as in Jira, so "done" is known whatever the column names. A new board starts with three columns: TO-DO, IN PROGRESS, DONE (localised).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Tasks                          | Quick add at the bottom of each column (type a title, press Enter): the task goes to the bottom of the column and the field stays open for the next one; Escape closes it. "New task" (or `N`) opens quick add in the first column. Fields of the detail window save as soon as they change. Details open in a centred window over the dimmed board, which can be expanded to full screen.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Drag and drop                  | Between columns (changes status) and within a column (changes order). Also doable with the keyboard: ⌥/Alt + ↑↓ changes the order, ⌥/Alt + ←→ the column; ⌥/Alt + ←→ on a focused column header moves the column.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Task fields                    | Title (required). Description (optional). Status (first column by default). Priority on five levels, Very low → Very high, **Medium by default**. Start date and due date (optional, **day only, no time**); the due date cannot be before the start date.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Sub-tasks                      | **One level only.** Tasks attached to a parent task, with their own title and status (their column), priority, dates, tags, notes and attachments; they are not cards of the board. On the parent card they show as a progress ring (e.g. 3/5), in the detail window as a list: checking one sends it to the first Done column, unchecking to the first To-do column, its status opens the list of columns; its title opens its own window (breadcrumb Board › Parent › Sub-task, with a way back to the parent). A new sub-task goes to the first To-do column, at the end of the list. Deleting a task sends its sub-tasks to the trash with it; deleting a column also takes the sub-tasks inside it.                                                                                                                                                                                                                                             |
| Tags                           | **Scoped to a board**, names unique per board ignoring case and accents, listed alphabetically. One colour per tag: a new tag takes the first colour no tag of the board uses (blue first), changeable later. Autocomplete and inline creation from the task. Renaming, recolouring and deleting a tag (permanently, after a confirmation that says how many tasks lose it) happen from the tag picker. On a card, tags fit on one line and the rest is summed up as "+N".                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Rich description (note taking) | Rich editor: headings, lists, checkboxes, code blocks, quotes, links, tables, pasted images. Markdown shortcuts, "/" menu, autosave 500 ms after the last keystroke. A toolbar stays above the notes. Links open in the default browser (button, ⌘/Ctrl + click). Pasted or dropped images are copied as attachments of the task and can be resized; a table grows with "+" bands and its rows and columns are deleted from a right-click menu.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
