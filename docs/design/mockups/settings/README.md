# Settings — chosen layout 2026-10-10

Design canvas "Ordo — Maquettes", page "Réglages — tour 1".

`Settings.dc.html` — `mode` prop: `modal` (chosen) or `page` (rejected).

| Element | Decision |
| --- | --- |
| Opening | Centred window (980 px, 64 px from top and bottom) over the dimmed board, opened from "Settings" at the bottom of the sidebar |
| Navigation | Left list (220 px): Appearance, Language, Data, Keyboard shortcuts, About; the content area scrolls |
| Appearance | Mode Light / Dark / System (segmented). Colour theme: five cards with a mini board drawn in each theme (Ciel default, Aurore, Lavande, Indigo, Corail); the choice applies live to the whole app |
| Language | Français / English as radio cards, each with a date example |
| Data | Database path, size and counts, "Open folder"; trash (kept 30 days) with "View trash" and "Empty now" |
| Keyboard shortcuts | Read-only list for the MVP shortcuts |
| About | App icon, version, one line on offline storage |
| Later (V1) | Automatic backups and JSON export/import get their own block under Data |
