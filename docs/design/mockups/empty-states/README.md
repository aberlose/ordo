# Empty states — approved 2026-10-10

Design canvas "Ordo — Maquettes", page "États vides et palette". `EmptyStates.dc.html`, `mode` prop: `first` or `board`.

| State | Decision |
| --- | --- |
| First launch | Sidebar shows "No board yet" (dashed box). Centre: app icon, "Welcome to Ordo", one line on offline storage, two option cards: **Create an empty board** (To do / In progress / Done) and **Discover with an example** (demo tasks, deletable). Tip line about ⌘K |
| New empty board | The three default columns with their icons. First column: dashed box "No task yet", hint with the `N` shortcut, "Add a task" button. Other columns: dashed drop zone "Drag a task here". Filter bar dimmed while the board has no task |
| Empty column under filters | See the board README ("No task matches the filters") |
