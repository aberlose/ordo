Le client veut un header plus compact : logo à gauche, recherche intégrée, et un seul niveau de navigation. La maquette a été validée le 30 sept. (voir pièce jointe maquette-header-v3.png).

Points d'attention

  • Le header reste sticky uniquement sur la page produit.
  • Hauteur maximale de 64 px sur desktop, 56 px sur mobile.
  • Le menu burger doit être utilisable au clavier (Échap ferme le menu).
.site-header {
  position: sticky;
  top: 0;
  height: var(--header-h, 64px);
}
« On garde le bleu du logo, mais le fond du header doit rester blanc. » — retour client du 2 oct.
